# ImbutoSmart AI — Documentation

ImbutoSmart AI is a **hybrid agricultural decision-support system** for Rwanda. It works with an internet connection and it keeps working without one, using the model, the crop rules and the district record carried on the device.

This folder holds the project documentation:

- [ImbutoSmart AI](imbutosmart-ai.md) — what the system is, how the hybrid design works, the data and models behind it, the pages a farmer uses, AI and language support, privacy, running and deployment.

The same description is available at the repository root as [`Documentation.md`](../Documentation.md), for readers who look there first.
